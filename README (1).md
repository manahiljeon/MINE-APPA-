# Appa Surprise Website 🐰🤍

A premium, responsive surprise website created with love for Appa.

This project is a small digital surprise designed to express heartfelt feelings through a beautiful, interactive web experience. It combines a soft cream and pink aesthetic with elegant animations, bunny-inspired details, and meaningful messages.

## ✨ Features

- Premium cream and pink design
- Fully responsive for mobile and desktop
- Animated opening surprise
- Smooth scrolling and elegant transitions
- Bunny-inspired visual theme
- Heartfelt personal messages
- Clean and modern user interface
- Built with simple HTML, CSS, and JavaScript

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📱 Responsive Design

The website is designed to provide a beautiful experience across different screen sizes, including mobile phones, tablets, and desktop computers.

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `appa_wow_bunny_feelings.html` in your browser.
4. The website will start automatically.

No installation or additional setup is required.
